はじめに

itoyomi は、閲覧中のページに表示される文（画面の少し上下の、まだ見えていない部分も含みます）を、攻撃・煽り・口論の判定のために外部へ送ります。

  • 送り先: 判定を行う TypeSafe（AI の会社）。無料枠では、開発者が利用料を払うための中継サーバーを経由します（自分の API キーを入れた場合は、直接 TypeSafe に送ります）。
  • 使い道は判定だけです。中継は文を保存しない作りです
  • メール・銀行・AI チャットなどは既定で対象外です（設定で追加できます）

留意事項: ソースコードは公開していますが、中継については、公開しているコードと実際に動いているものが同じであることを、今の仕組みでは利用者が確かめる方法がありません。一方、拡張機能のコードは利用者のブラウザの中で動くので、公開しているコードと見比べて確かめられます。オフにしている間は文を一切送らないことも、そのコードから分かります。中継が気になる場合は、拡張機能をオフにするか、ご自身の TypeSafe API キーを設定してください（中継を通らなくなります）。
