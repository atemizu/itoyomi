# itoyomi

意図を読んで、意図の単位で隠す。（名前は `manifest.json` の `name` の 1 か所。変えるときはそこと、この見出しを直す。）

開いたページの文を jev（TypeSafe System One, `POST https://api.typesafe.ai/v1/systemone`）に送り、
対立的（攻撃・侮辱／煽り・分断／口論）と判定された文を隠す Chromium 拡張機能（Manifest V3）。

## 入れ方

1. `brave://extensions`（Helium / Chrome は `chrome://extensions`）を開き、「デベロッパー モード」を入れる
2. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選ぶ（更新したときは ↻ を押す）
3. そのまま動く（無料枠）。「文で試す」に文を貼って「判定」を押すと点数がわかる
4. 自分の TypeSafe の API キーを使うなら、ツールバーのアイコンからキーを入れて「保存」

## 無料枠と自分のキー

- **キーなし（既定）= 無料枠**: 実験として開発者が利用料を負担している。予告なく終了することがある。
  画面に出た文は、運営者の中継（`jev.js` の `RELAY`、Cloudflare Workers）を経由して TypeSafe に送られます。開発者が内容を見られないよう、中継は文を保存せず、ログにも出さない作りにしています。拡張機能と中継のコードは GitHub で公開しています。
  1 人 1 日の上限があり（日本時間の午前 9 時に戻る）、こちら側でも 1 日 3,000 件で止める。
- **キーあり**: 中継は通らず、直接 TypeSafe (`api.typesafe.ai`) に送る。料金は自分の負担。
- 無料枠が終了・上限・失敗のとき、また jev が失敗したときは、何も隠さない（文はそのまま見える）。理由はポップアップに出る。

TypeSafe 社とは無関係の非公式の拡張機能。コードは AI (Claude) が書いたもので、開発者が全行を人手で検証したわけではない。誤判定がある。重要な判断の根拠にはしないこと。

## どこに効くか

- **対応サイト**（投稿 1 件を正確に取る。`content.js` の `SITES`）:
  X、Bluesky、YouTube（コメント・返信・ライブチャット・コミュニティ投稿・動画タイトル）、
  ニコニコ動画（コメント一覧・流れるコメント・動画カード）、ニコニコ生放送（コメント欄）、ニコニコ大百科、
  Reddit（新旧）、Yahoo!ニュースのコメント、5ch、おーぷん2ch、Hacker News、Mastodon（画面で見分ける）、Threads、Togetter。
- **それ以外の全ページ**（`generic.js` の汎用検出）: 文字のかたまり（段落・コメント・見出しなど）を自動で拾う。
  入力欄・エディタ・コード・メニュー類は拾わない。設定で切れる。

### 自動では拾わない所

- 「使わないサイト」に入っているホスト（既定の一覧は `defaults.js`。メール・チャット・書類・AI チャットなど）
- 汎用検出だけ（対応サイトの規則には掛からない。すべては網羅できない）: 見えているパスワード欄があるページ、銀行・メール・ログインらしいホスト名、IP アドレスや localhost、枠まるごとのエディタ、
  親と別オリジンの枠（広告など）

## しくみ

- `content.js` — 文を見つけ、画面の近くに 0.4 秒留まったものだけ背景へ送る。1 ページが送れる速さは毎秒 3 件まで（最初だけ 40 件まで）。
  書き換わり続ける文は相手にしない。返ってきた点数がしきい値以上なら要素に `data-jevh` 属性を付ける。
  ページにノードは足さない（見た目は `content.css`）。
- `background.js` — jev を呼ぶ。同時に 6 件、1 件 10 秒で打ち切り、408/429/5xx は間を空けて 2 回まで聞き直す。
  同じ文は 4,000 件まで覚えて呼び直さない（IndexedDB）。401/403 は 10 分、429 は 30 秒、要求が通らないときは 5 分休む。
  1 日の上限（既定 20,000 件）を超えたら呼ばない。チャット・流れるコメントはその半分まで。
- `jev.js` — 質問の組み立てと答えの読み取り。1 つの文につき 1 要求で、`noul`（はい/いいえの確率）を 3 つ聞く。
  有効な種類のうち最大の確率がしきい値（既定 50%）以上なら隠す。3 つとも毎回聞いて点数を覚えるので、
  しきい値や種類の切り替えは呼び直しなしで即座に効く。
- `nico-main.js` — ニコニコ動画のページ側で動く。コメント取得の応答を読むだけ読み（応答は変えない）、
  隠すと決まったコメントは canvas に描く段で描かない。判定は再生位置の 2 分先までを、再生に合わせて進める。
- `popup.html` / `popup.js` — 設定と今日の集計（問い合わせ件数・入力トークン・概算の料金）。

## 送るもの

画面の近く（上下 1 画面ぶん）にある投稿・段落の文（1 件 3,000 字まで。たたまれて見えていない部分を含むことがある。ニコニコ動画では再生位置の約 2 分先までのコメント本文）。
ページの URL・タイトル・Cookie・入力欄の中身や、投稿者名などの付随情報を別に付けて送ることはない。ただし、画面に出ている文そのものに名前などが含まれていれば、文の一部として送られる。
無料枠では、上限の管理のために、拡張機能ごとの乱数の ID（`X-Install-Id`。入れ直すまで同じ）が付き、中継は IP アドレスから日ごとに作った値（元の IP は保存しない）も使う。質問文は中継が組む。
自分のキーでは、固定の英語の質問文とモデル名が付き、そのキーの TypeSafe アカウントの利用として送られる。
どちらの場合も、通常のウェブ通信と同じく IP アドレスやブラウザの種類は相手に伝わる。
ページ自身のスクリプトは、どの文が隠されたか（`data-jevh` 属性）を知ることができる。
要求に Cookie・Referer は付けない（`credentials: 'omit'`, `referrerPolicy: 'no-referrer'`）。
API キーはこのブラウザの拡張機能の保存領域 (`chrome.storage.local`) にだけ置く。
汎用検出は「全ページ」が対象なので、人に見せたくない文面が出るサイトは「使わないサイト」に足す
（ポップアップの「〜では使わない」で今のサイトを足せる）。

## 確かめ方

```sh
node --test test/jev.test.mjs
```

ストアに出す zip は `tools/pack.sh`（出力は `~/Downloads/<名前>-<版>.zip`）。アイコンは `icons/icon16.png`・`icon32.png`・`icon48.png`・`icon128.png`（PNG、それぞれその辺の長さの正方形）を置く。
手元のフォルダの `manifest.json` にはアイコンの指定を入れていない（ファイルが無いと Chrome が読み込みを拒むため）。`pack.sh` が zip の中の manifest にだけ足し、足りなければ止まる。
質問文（`jev.js` の `QUESTIONS`）を変えたら、中継側の写しも更新して配り直す。

実ページでの確認は `test/live/`（拡張機能の代わりに偽の判定を差し込む束）。`python3 test/live/serve.py` で配り、
`http://127.0.0.1:8765/test/live/smoke.html` を開く。束は `content.js` などを変えたら作り直す。

質問文を変えたら `jev.js` の `QUESTION_VERSION` を上げる（古い点数を使わないため）。
サイトを足すときは `content.js` の `SITES` に 1 行足す。目隠しの CSS は `content.css` と `generic.js` の `CSS` の両方にある。
